Using ChatGPT inside Microsoft PowerPoint

The new ChatGPT Office add-in makes PowerPoint feel less like a blank canvas and more like a place where a draft can start moving quickly: install the add-in, open the ChatGPT sidebar, sign in, and ask it to create, edit, understand, or polish slides in the deck itself.

Prepare Microsoft 365

If Microsoft 365 is not installed yet, this cnblogs post is a useful reference for the Office Tool Plus deployment flow: Microsoft 365 installation notes.

One practical caveat: for a machine you rely on, use a legitimate Microsoft subscription, school or company license, family sharing, or another properly authorized route. Third-party activation tools and KMS servers can create compliance, security, and reliability problems, so I would not treat them as the foundation for a long-term work setup.

Install ChatGPT

Install the ChatGPT Office add-in from Microsoft Marketplace. The same add-in can also be found from inside PowerPoint: open Home, choose Add-ins, search for ChatGPT, and add it.

After installation, reopen or bring up PowerPoint and launch ChatGPT from the ribbon. When the sidebar appears, sign in with the OpenAI / ChatGPT account that has access, then start working directly inside the presentation.

Useful first prompts

  • Turn a memo, abstract, or meeting note into a short slide deck.
  • Add a background, risks, or summary slide to an existing deck.
  • Review the story, gaps, and audience fit of the presentation.
  • Polish titles and bullets while preserving the current template.

The final review still matters. ChatGPT for PowerPoint is currently a beta experience, and generated slides or edits may need manual cleanup. Check facts, numbers, citations, and formatting before sharing the deck.
