Reusable Codex Skill

slideslive-pptx

A small Codex skill for reconstructing SlidesLive presentations that do not expose a download button. It downloads hidden slide images, rebuilds a PPTX, and can merge incremental reveal frames.

View raw SKILL.md Rebuild script Merge script

What it does

  • Finds the SlidesLive embed page for a presentation.
  • Extracts the hidden slides.json manifest.
  • Reconstructs numeric-quality CDN image URLs.
  • Builds a visually faithful PPTX from image slides.
  • Optionally merges additive reveal frames into a compact deck.

Typical prompt

Use the slideslive-pptx skill to download this SlidesLive talk as a PPTX,
then merge incremental reveal frames.

Install idea

Copy the slideslive-pptx folder into your local Codex skills directory, or adapt the scripts directly for one-off use.
